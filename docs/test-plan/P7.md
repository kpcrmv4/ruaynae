**หลักฐาน:** `verify-pwa.mjs` (27) — อยู่ใน `npm run verify:all`

**สิ่งที่ตารางแถวนี้จับได้ตั้งแต่วันแรก** — `P7-INF-06` ตอบ **307**:
`offline.html` ไม่ได้ถูกยกเว้นใน matcher ของ `proxy.ts` · service worker แคช
หน้านี้ตอน `install` ซึ่งเกิดขึ้นได้ตอนยังไม่ล็อกอิน → มันจะแคช **หน้า login**
ไว้ในชื่อ "หน้าออฟไลน์" แล้ววันที่เน็ตหลุดจริง ผู้ใช้จะเห็นหน้าล็อกอิน
แทนคำอธิบาย · ตระกูลเดียวกับ `sw.js` ที่โดน 307 ซึ่งเคยระวังไว้แล้ว
แต่ไฟล์ใหม่ที่เพิ่มทีหลังไม่ได้ถูกเพิ่มเข้าไปในรายการยกเว้นด้วย

**กฎการติ๊ก** — แถวที่ ID มี `-DB-` `-API-` `-INF-` ต้องมี ID อยู่ใน label ของ check
ที่รันได้จริงใน `scripts/**` · กระทบยอดด้วย `node scripts/verify-matrix.mjs`

**ยังไม่ทำในเฟสนี้ — อยู่ในเช็คลิสต์ก่อน deploy**
- ตั้ง pg_cron ให้เรียก `/api/cron/push-dispatch` ทุกนาที และ `sweep-orphans` ทุกชั่วโมง
  (ต้องมี URL สาธารณะก่อน · ตั้งตอนนี้ = งานที่ยิงไปที่ที่ไม่มีอยู่ แล้ว log error ทุกนาที)
- ไอคอนตอนนี้เป็นหมวกนิรภัยที่ระบบวาดเอง — เปลี่ยนเป็นโลโก้จริงเมื่อเจ้าของส่งไฟล์มา
- `VAPID_SUBJECT` ต้องเป็นอีเมลจริง ไม่ใช่ `mailto:` เปล่า ๆ (dispatch ตอบ 503 ถ้ายังไม่ตั้ง)
