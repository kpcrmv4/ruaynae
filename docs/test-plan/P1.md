## P1-CALC — ความคืบหน้า 3 แถบ

> 🔴 **ห้ามให้แถวใดผ่านบน `0 === 0`** — ทุกแถวต้องสร้างข้อมูลเข้าไปก่อน
> ไซต์ที่ไม่มีรายการเลยจะได้ 0 ทุกช่อง ซึ่งตรงกันสามชั้นโดยไม่ได้พิสูจน์เลขสักตัว
> fixture ทุกตัวคืนค่าใน `finally`

| P1-CALC-02 | วันนี้อยู่ **ก่อน** วันเริ่ม | owner | แถบเวลา **0%** ไม่ใช่ค่าติดลบ | n/a | n/a | n/a | ☐ |

## สรุปความครอบคลุม

```
รวม 37 แถว
  ✅ ผ่านโดยมีคำสั่งรันได้รองรับ : 10  ← P1-DB ทั้งหมด
  ☐  ยังไม่ตรวจ                  : 25  (UI/API/CALC รอโค้ด)
  ⚠️ blocked (รอข้อมูลจริงจาก P2/P4) : 2   ← P1-CALC-07, P1-CALC-08
  ❌ ตก                          : 0
```

**กฎการติ๊ก** — แถวที่ ID มี `-DB-` `-CALC-` `-API-` ต้องมี ID อยู่ใน label ของ check
ที่รันได้จริงใน `scripts/**` · ติ๊กจากความจำไม่นับ
**และห้ามติ๊กแถวคำนวณที่ input ยังเป็นศูนย์** — ต้องสร้างข้อมูลเข้าไปก่อน แล้วคืนใน `finally`
