# R10 · รายการปรับค่าแรง (OT · เบี้ยเลี้ยง · มาสาย) + แก้ค่าแรงที่จ่ายจริง — ตารางตรวจรับ

> คำสั่งเจ้าของ 19 ก.ย. 2569:
> 1. *"ตรงนี้อยากให้เพิ่มตัวเลือกอิสระได้ โดยให้เป็นการตั้งค่าได้ในหน้าตั้งค่า เป็นค่าใช้จ่ายพิเศษ
>    หรือหักได้ … ปุ่มเครื่องหมายบวกเวลาเลือกชื่อ แล้วแสดง modal รายการ … แก้ไขได้ เช่น
>    OT/เบี้ยเลี้ยง/มาสาย และด้านล่างสามารถพิมพ์ได้เอง โดยเลือกว่าจ่ายเพิ่มหรือหักออก
>    แล้วมีสรุปว่าค่าแรงของคนนี้เท่าไหร่ในช่องชื่อคนที่เลือกเลย"*
> 2. *"แถบสรุป … ไม่ต้องทำให้มันลอยตามจอ ให้มันแสดงด้านบน … ให้ดูเหมือนเป็นข้อมูลสรุปสำคัญ"*
> 3. แท็บ "ทำงานที่ไหนบ้าง": *"แก้ไขค่าแรงที่จ่ายจริงของพนักงานรายคนที่ยังไม่จ่ายได้ … ไอคอนดินสอ
>    … modal … ข้อความแจ้งว่า การแก้ไขค่าแรงนี้ จะแก้ไขค่าใช้จ่ายของโครงการด้วยทันที
>    … มีตัวเลือกพวกค่าจ่ายพิเศษและ OT รวมถึงรายการหักด้วย"*

**สถานะ:** `☐` ยังไม่ตรวจ · `✅` ผ่านโดยมีหลักฐาน · `❌` ตก · `👤` ต้องคนตรวจ

> 👤 = ต้องมี dev server + เบราว์เซอร์จริง · ✅ ฝั่ง DB ตรวจบนโปรเจ็คจริง `kdftrlagqovjsgejahwz`
> ผ่าน MCP 19 ก.ย. 2569 (apply `wage_adjustments` + `wage_adjustments_drop_ot_check` +
> `supervisor_many_sites` · generate types · advisors)
