# R8 · มุมมองการ์ดของรายชื่อคนเข้าโครงการ — ตารางตรวจรับ

> คำสั่งเจ้าของ 1 ก.ย. 2569: *"หน้าคนเข้าโครงการ ตรงการ์ดยังไม่เข้า เพิ่มปุ่มสลับมุมมอง
> แล้วให้รายชื่อพนักงานเป็นการ์ดสี่เหลี่ยมเล็กๆ ให้กดง่ายๆ สำหรับใช้นิ้วเดียว
> เพื่อเลือกชื่อพนักงานได้ง่ายที่สุด"*
>
> งานจริงคือ **ยืนกลางโครงการ ถือมือถือมือเดียว แล้วไล่แตะชื่อคนสิบกว่าคน** —
> แถวเต็มความกว้างบังคับให้กวาดนิ้วขึ้นลงทั้งจอ ตารางสองคอลัมน์เอาชื่อมาอยู่
> ในระยะนิ้วโป้งและเห็นได้ครั้งละหลายคน

**สถานะ:** `☐` ยังไม่ตรวจ · `✅` ผ่านโดยมีหลักฐาน · `❌` ตก · `👤` ต้องคนตรวจ

> 👤 = ต้องมี dev server + เบราว์เซอร์จริง · เครื่องรอบนี้ไม่มี `.env.local` ของจริง
> · แถวที่ตรวจด้วย HTML ที่เซิร์ฟเวอร์เรนเดอร์อยู่ใน `verify-attendance`

## 2 · สิ่งที่ **ไม่** เปลี่ยน

- กติกาการลงชื่อทั้งหมด (เพดาน 1 วัน/คน/วัน · โครงการที่ดูแล · วันในอนาคต) ยังบังคับที่
  API และฐานข้อมูลเหมือนเดิม — มุมมองนี้ไม่ได้เพิ่มหรือลดสิทธิ์อะไรเลย
- ปุ่ม "เหมือนเมื่อวาน" · "เลือกทุกคน" · แถบสรุปลอยล่าง ทำงานเหมือนเดิมทั้งสองมุมมอง
- ค่า `picked` / `half` / `ot` เป็น state ชุดเดียวกัน สลับมุมมองแล้วไม่หาย
