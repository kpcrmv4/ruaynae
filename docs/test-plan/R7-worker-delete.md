# R7 · ลบคนงาน + จัดหัวหน้าคนงานบนจอเล็ก — ตารางตรวจรับ

> คำสั่งเจ้าของ 1 ก.ย. 2569: *"ทำให้หน้า workers สามารถลบคนงานได้ด้วยนะ
> โดยถ้าคนนี้ยังไม่จ่ายค่าแรงตอนกดลบให้เตือนและมีข้อมูลบอกให้ด้วย"*
> และ *"หน้า workers จัดระเบียบส่วนหัวตรงนี้ให้ด้วยนะ ในจอเล็กมันรกมาก"*
>
> **เส้นแบ่งของการลบ = เงินที่จ่ายออกไปแล้ว** ไม่ใช่ "มีประวัติหรือเปล่า"
> · ยังไม่เคยปิดรอบจ่าย → ลบได้ พร้อมเตือนยอดค้างจ่ายที่กำลังจะหายไป
> · เคยอยู่ในรอบจ่ายที่ปิดแล้ว → ลบไม่ได้ (`payroll_lines` คือหลักฐานการจ่ายเงิน)
> ใช้ "ปิดใช้งาน" ที่มีอยู่แล้วแทน

**สถานะ:** `☐` ยังไม่ตรวจ · `✅` ผ่านโดยมีหลักฐาน · `❌` ตก · `👤` ต้องคนตรวจ · `⚠️` ปิดไม่ได้พร้อมเหตุผล

> 👤 = ต้องมี dev server + เบราว์เซอร์ · เครื่องที่ทำรอบนี้ไม่มี `.env.local` ของจริง
> จึงรัน `scripts/verify-workers.mjs` ไม่ได้ · แถว DB ตรวจบนฐานข้อมูลจริงด้วยธุรกรรม
> ที่ **ย้อนกลับทั้งก้อน** ผลอยู่ในช่อง "หลักฐาน"

## 1 · R7-DB — กฎที่ฐานข้อมูลบังคับ

| ID | Trigger | ผลที่คาด | หลักฐาน | สถานะ |
|----|---------|----------|---------|--------|
| R7-DB-01 | `employees_delete_info()` ของคนที่ลงชื่อ 1 วัน (เรต ฿400) และเบิกไป ฿150 | คืนตัวเลขครบ และ **ใช้สูตรเดียวกับ `employee_balance()`** | `days=1.00 unpaid=400.00 advance=150.00 advn=1 lines=0` | ✅ |
| R7-DB-02 | `delete_employee()` กับคนคนเดียวกัน | สำเร็จ · คืนยอดที่หายไป · แถว `attendance` / `advances` / `employee_wages` หายตามครบ | `ลบแล้ว days=1.00 unpaid=400.00 adv=150.00` · ไม่เหลือแถวใด | ✅ |
| R7-DB-03 | `delete_employee()` กับคนที่มี `payroll_lines` ของรอบที่ปิดแล้ว | `EMPLOYEE_IN_PAYROLL` · แถวยังอยู่ครบ | `B=EMPLOYEE_IN_PAYROLL` | ✅ |
| R7-DB-04 | `delete_employee()` ขณะสวมสิทธิ์ **หัวหน้าโครงการ** | `FORBIDDEN` — `security definer` ข้าม RLS ไปแล้ว การเช็คต้องอยู่ในฟังก์ชัน | `C=FORBIDDEN` | ✅ |
| R7-DB-05 | `employees_delete_info()` โดยคนที่ไม่ใช่เจ้าของ | **0 แถว** — ยอดค่าแรงเป็นข้อมูลของเจ้าของเท่านั้น (P4.5) | `D=0 แถว` | ✅ (ซ้ำใน `verify-workers`) |
| R7-DB-06 | ลบคนงานจริง 2 คนที่เจ้าของขอ (`คนงานทดสอบ1` · `คนงานทดสอบ2`) | หายจากตาราง · `audit_log` มี `action='DELETE'` สองแถวพร้อม `before` ทั้งแถว | `employees_left=0` · audit DELETE 2 แถว (1 ก.ย. 2569) | ✅ |
