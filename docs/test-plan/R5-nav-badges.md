# R5 · ตัวเลขของค้างบนเมนู — ตารางตรวจรับ

> คำสั่งเจ้าของ 1 ก.ย. 2569: *"เพิ่มตัวเลขแจ้งเตือนที่เมนูให้หน่อย"* →
> เลือกแบบ **"ตัวเลขของค้างทุกเมนู"** (ไม่ใช่ย้ายเลขกระดิ่งมาไว้บนเมนู)
>
> **ไม่มีการแก้ฐานข้อมูล/สิทธิ์/endpoint** — เป็นการอ่านนับเพิ่มสองอันใน `(app)/layout.tsx`
> `tsc` เขียวและ `next build` เขียว **ไม่นับ**เป็นหลักฐานของแถวใดในนี้

**สถานะ:** `☐` ยังไม่ตรวจ · `✅` ผ่านโดยมีคำสั่งรันได้รองรับ · `❌` ตก · `⚠️` blocked · `👤` ต้องคนตรวจ

> 👤 ของรอบนี้ = แถวที่ต้องเปิดเบราว์เซอร์จริง (แผ่น "เพิ่มเติม" เป็น Radix Portal
> ที่ไม่ถูกเรนเดอร์ลง HTML จนกว่าจะกดเปิด จึงวัดจาก HTML ฝั่งเซิร์ฟเวอร์ไม่ได้)
> · เครื่องที่ทำรอบนี้ไม่มี `.env.local` จึงยังไม่ได้รัน `verify-shell` จริง

---

## 0 · สิ่งที่เปลี่ยน

| อะไร | ไฟล์ |
|---|---|
| ที่มาของตัวเลข (ที่เดียว) | `src/app/(app)/layout.tsx` → `navBadges` |
| ชนิด + ตัวช่วยรวมยอด | `src/components/shell/nav.ts` → `NavBadges` · `badgeOf` · `badgeTotal` · `badgeText` |
| ป้ายบนเมนู | `sidebar.tsx` · `bottom-nav.tsx` (ช่อง · ปุ่ม "เพิ่มเติม" · แถวในแผ่น) |
| ตัวนับที่เพิ่ม | `transactions` ที่ `status='rejected'` (`head: true, count: 'exact'`) |

**เมนูที่มีตัวเลขได้ตอนนี้**

| เมนู | ความหมาย | ใครเห็น |
|---|---|---|
| รออนุมัติ (`/approvals`) | รายจ่ายที่หัวหน้าไซต์คีย์และยังไม่อนุมัติ | เจ้าของ |
| รายรับ-รายจ่าย (`/ledger`) | รายการที่ถูกตีกลับและยังไม่ถูกแก้ (ขอบเขตตาม RLS) | ทั้งสอง role |
| "เพิ่มเติม" | **ผลรวม**ของเมนูที่ถูกซ่อนอยู่ในแผ่นนั้น | มือถือ |

## 1 · R5-NAV — ป้ายตัวเลข

| ID | Trigger | Role | ผลที่คาด | สถานะ |
|----|---------|------|----------|--------|
| R5-NAV-01 | มีรายจ่ายรออนุมัติ | owner | ป้ายบน "รออนุมัติ" = จำนวนจริง **ทั้ง sidebar และแถบล่าง** (ตัวเลขเดียวกัน) | ✅ `verify-shell` |
| R5-NAV-02 | มีรายการที่ถูกตีกลับค้างอยู่ | owner | ป้ายบนเมนู "รายรับ-รายจ่าย" = จำนวนจริง ทั้งสองแถบ | ✅ `verify-shell` |
| R5-NAV-03 | เมนูที่อยู่บนแถบล่างแล้ว | owner | **ไม่ถูกนับซ้ำ**ที่ปุ่ม "เพิ่มเติม" · เมนูที่ไม่มีตัวนับ (เช่น ไซต์งาน) ไม่มีป้าย | ✅ `verify-shell` |
| R5-NAV-04 | มีของถูกตีกลับในไซต์ที่ดูแล | site_supervisor | เห็นป้ายบนช่อง "รายการ" · ไม่มีช่อง "รออนุมัติ" ให้ติดป้ายเลย | ✅ `verify-shell` |
| R5-NAV-05 | ของค้างหมด | owner | ป้ายกลับไปเท่าค่าตั้งต้น · **ค่า 0 ไม่ถูกวาดเป็นป้าย** | ✅ `verify-shell` |
| R5-NAV-06 | เมนูที่มีของค้างถูกซ่อนอยู่ในแผ่น "เพิ่มเติม" | ทั้งคู่ | ปุ่ม "เพิ่มเติม" ขึ้นผลรวม และแถวในแผ่นขึ้นตัวเลขของตัวเอง | 👤 |
| R5-NAV-07 | เปิดแผ่น "เพิ่มเติม" | ทั้งคู่ | แถวที่มีของค้างมีป้ายอยู่ในแถว (ไม่ใช่มุมไอคอน) และไม่ดันชื่อเมนูจนตกบรรทัด | 👤 |
| R5-NAV-08 | โปรแกรมอ่านหน้าจอ | ทั้งคู่ | ลิงก์ที่มีป้ายอ่านว่า "‹ชื่อเมนู› · ค้าง N รายการ" ไม่ใช่อ่านแค่ชื่อเมนู | 👤 |
| R5-NAV-09 | จอ 390 / 768 / 1440 · สว่างและมืด | ทั้งคู่ | ป้ายอ่านออกทั้งสองธีม (`--urgent-solid` + ตัวขาว) · ไม่ล้นออกนอกช่อง · ชื่อช่องไม่ตกบรรทัด | 👤 |
| R5-NAV-10 | ตัวเลขเกิน 99 | owner | แสดง "99+" ไม่ใช่เลขยาวจนดันเมนูเสียรูป | 👤 |
