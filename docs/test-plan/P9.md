# P9 · ตัวเชื่อม MCP อ่านอย่างเดียว — ตารางตรวจรับ

> เขียน**ก่อน**โค้ด ตาม `kp-acceptance-test-matrix`
> `tsc` เขียวและ `next build` เขียว **ไม่นับ**เป็นหลักฐานของแถวใดในนี้
> อ้างอิงสเปก `docs/superpowers/specs/2026-08-31-mcp-analytics-connector-design.md` §11

**สถานะ:** `☐` ยังไม่ตรวจ · `✅` ผ่านโดยมีคำสั่งรันได้รองรับ · `❌` ตก · `👤` ต้องคนตรวจ (เครื่องจริง/สายตา) · `⚠️` ปิดในเฟสนี้ไม่ได้ พร้อมเหตุผลกำกับในแถว

> 🔴 **ตัวเชื่อมนี้พังแบบที่ไม่มี error ให้เห็น** — header `WWW-Authenticate` ที่ใส่เพิ่มเพราะดู
> "ถูกต้องตามสเปก" จะทำให้ Claude เริ่ม OAuth discovery แล้วค้างหลังปุ่ม Connect ตลอดไปโดยไม่มี
> ข้อความ error ที่ไหนเลย · เรียก RPC เงินเดิมตรง ๆ ด้วย `service_role` จะได้ `null` ทุกคอลัมน์เงียบ ๆ
> เพราะ `auth.uid()` เป็น null แต่ AI จะไม่ฟ้อง แค่ตอบคำถามผิดด้วยความมั่นใจ · `resources/*` ที่ตอบ
> `-32601` แทน `[]` ทำให้แอป Claude โชว์ข้อความแดงทั้งที่เราไม่เคยประกาศ capability นั้น · ทุกแถว
> ในตารางนี้จึงเน้นตรวจสิ่งที่ **ดูเหมือนทำงานแต่ตอบผิด** ไม่ใช่สิ่งที่พังจนเห็นชัดจากหน้าจอ

- แถวที่ `-DB-` `-FN-` `-PROTO-` `-TOOL-` `-SEC-` ปิดด้วย `✅` เมื่อมี `scripts/verify-mcp.mjs` รองรับเท่านั้น
- แถว `-UI-` ปิดด้วย `👤` จากการตรวจในเบราว์เซอร์จริงที่ความกว้าง **390 / 768 / 1440** ทั้งโหมดสว่างและมืด ตาม `CLAUDE.md` §16
- แถว `P9-SHIP-01` เป็น `👤` ตั้งแต่ต้น ปิดในเครื่องไม่ได้ตามเหตุผลในแถว — **ห้ามติ๊ก `✅` จากการเดา**
- **ห้ามเหลือ `☐` แม้แต่แถวเดียว** ตอนปิดเฟส (`CLAUDE.md` §17 ข้อ 10) — ปิดไม่ได้ต้องเปลี่ยนเป็น `👤` หรือ `⚠️` พร้อมเหตุผลที่เขียนไว้จริงในแถว ไม่ใช่ปล่อยว่าง

**กฎการติ๊ก** — แถวที่ ID มี `-DB-` `-FN-` `-PROTO-` `-TOOL-` `-SEC-` ต้องมี ID อยู่ใน label ของ
`check()` ที่รันได้จริงใน `scripts/verify-mcp.mjs` ตัวอักษรตรงกับ ID ในไฟล์นี้เป๊ะ ๆ — เพื่อให้
`node scripts/verify-matrix.mjs` (ถ้ามี) กระทบยอดได้

**ยังไม่ทำในเฟสนี้ — ตัดออกโดยตั้งใจ (สเปก §2)**
- tool ที่เขียนข้อมูล (อนุมัติ / บันทึกรายจ่าย) — ให้ AI กดอนุมัติแทนเจ้าของคือความเสี่ยงคนละระดับ
- OAuth — คีย์ธรรมดาก็ถูกต้องตามสเปก MCP (Authorization เป็น OPTIONAL) และง่ายกว่ามากสำหรับคนที่ไม่ชำนาญคอม
- `run_sql` แบบเปิด — tool ที่รับ SQL ดิบคือช่องเขียน/อ่านทุกอย่างที่ปลอมตัวเป็น tool อ่านอย่างเดียว
- คีย์แบบจำกัดสิทธิ์รายไซต์ — มีแค่เจ้าของกับหัวหน้าไซต์ และหัวหน้าไซต์ไม่มีเหตุต้องต่อ AI (YAGNI)
- คู่มือสอนส่งคีย์ทาง `Request headers` — รองรับที่ endpoint แต่ไม่เขียนในคู่มือ (สองทางเลือก = สายโทรเข้า)
